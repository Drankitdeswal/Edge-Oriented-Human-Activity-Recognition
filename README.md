# Edge-Oriented Human Activity Recognition

## Overview

This project explores an Edge Computing based approach for Human Activity Recognition (HAR), with the objective of processing activity-related data closer to the data source.

The project focuses on the combination of:

- Edge Computing
- Artificial Intelligence / Machine Learning
- Human Activity Recognition
- Real-time Data Processing
- Distributed Computing

## Objective

The main objective is to explore how Edge Computing can support faster and more efficient Human Activity Recognition by reducing dependency on centralized cloud processing.

## Key Areas

- Edge-based data processing
- Human activity classification
- Machine Learning for activity recognition
- Reduced latency
- Cloud–Edge collaboration
- Efficient resource utilization

## System Architecture

The proposed Edge-Oriented Human Activity Recognition architecture follows a distributed processing approach in which activity-related data is processed closer to the source to reduce latency and unnecessary data transfer to the cloud.
